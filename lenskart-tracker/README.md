# Lenskart leadership brief (prototype, sample data)

Eight functions, one email. Every morning at 08:45 IST a GitHub Actions workflow refreshes the warehouse tables, runs data checks, works out each metric's red/amber/green from SQL, merges owners' project updates, picks the three things leadership must look at, emails it, and rebuilds the tracker page (`index.html`).

- `data/db/*.csv`: sample warehouse (stores, staff, roster, attendance, sales, online, hubs, lens lab, support, Gold, marketing, finance), generated by `scripts/generate.mjs`
- `scripts/metrics.mjs`: the 8 functions, 22 SQL metrics with targets, 7 data checks
- `data/projects.json`: milestone projects; owners update them by committing JSON to `data/inbox/` (that push triggers a run)
- `scripts/run.mjs`: the pipeline · `scripts/lib.mjs`: scoring, top-3, email rendering · `app/template.html`: the tracker page

Run locally: `node scripts/run.mjs`. Email goes out as a GitHub issue (GitHub emails repo watchers). For real email add the secrets `SMTP_SERVER`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `DIGEST_TO`.
